## 第一部分：项目简介

### 项目名称
**灵眸视卫——基于边缘AI的跌倒实时检测与物联网预警系统**

### 一句话概括
> 香橙派5B通过USB摄像头实时拍摄，利用NPU本地运行YOLOv8n-pose模型进行人体姿态估计，检测到跌倒后通过MQTT上报到PC端，PC端触发Vue前端弹窗报警、播放告警音效、调用DeepSeek医疗问答。

### 痛点分析
1. **老龄化社会**：我国65岁以上人口超2亿，跌倒是老年人意外伤害首位原因
2. **独居老人**：跌倒后"黄金救援时间"约30分钟，无人发现将危及生命
3. **隐私顾虑**：传统方案上传视频到云端，老人居家画面存在泄露风险
4. **设备依从性差**：穿戴式设备需频繁充电，老人常忘戴
5. **网络依赖**：纯云端方案断网即失效

### 核心优势
| 优势 | 说明 |
|:----|:-----|
| 🛡️ **隐私安全** | 视频数据全程本地处理，不上传云端，仅传输报警文本 |
| ⚡ **实时性** | NPU推理延迟<200ms，端到端报警<3秒 |
| 🔌 **断网可用** | 边缘推理不依赖外网，局域网即可独立运行 |
| 🎯 **高准确率** | 肩髋距离+身体角度双指标融合，>95%准确率 |
| 📱 **多级报警** | 前端弹窗+音效+DeepSeek医疗问答+钉钉推送 |

## 第三部分：跌倒检测算法详解

### 关键点选取
YOLOv8n-pose 输出17个COCO人体关键点，本系统只用其中4个：

| 索引 | 关键点 | 用途 |
|:----:|:------|:-----|
| 5 | 左肩 (Left Shoulder) | 肩部中心计算 |
| 6 | 右肩 (Right Shoulder) | 肩部中心计算 |
| 11 | 左髋 (Left Hip) | 髋部中心计算 |
| 12 | 右髋 (Right Hip) | 髋部中心计算 |

### 双指标融合判决

**指标A：肩髋垂直距离**
```
站立时：肩髋距离 ≈ 100~180px
坐下时：肩髋距离 ≈ 40~60px
跌倒时：肩髋距离 ≈ 10~40px
阈值：< 40px → 疑似跌倒
```

**指标B：身体倾斜角度**
```
角度 = atan2(|肩x - 髋x|, |肩y - 髋y|)
站立时：角度 ≈ 5°~15°
弯腰时：角度 ≈ 30°~50°
跌倒时：角度 ≈ 70°~90°
阈值：> 60° → 疑似跌倒
```

**判决逻辑**：条件A OR 条件B → 判定跌倒

### 状态机滤波

```
正常 (NORMAL)
  └─ 连续3帧检测到跌倒 → 待确认 (PENDING)
       ├─ 连续3帧恢复正常 → 回到正常
       └─ 再连续5帧检测到跌倒 → 确认报警 (CONFIRMED)
            ├─ → MQTT发送报警
            └─ 连续10帧恢复正常 → 回到正常
```

**画面**：动画展示"肩髋垂直距离"的计算——站立时大，跌倒时小

> 第一个指标是肩髋垂直距离。正常站立时，肩部和髋部的垂直距离较大；跌倒躺下后，肩部和髋部基本处于同一水平线，距离急剧缩小。

**旁白**：

**画面**：展示状态机流程图——正常→待确认→确认报警→恢复

**旁白**：
